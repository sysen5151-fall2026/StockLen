# StockLens UC.1 behavior reference

StockLens supports stock comparison for students and beginner investors. The Chapter 2 walking skeleton connects Dashboard/UI, StockLens System, market-data stub, news stub, ranking stub, internal AI coordination and external AI-service stub. It returns fixed fictional scores of 60 and 40 with a dated source. The local version uses HTTP; the static browser mirror runs in-process.

N-02: I need to understand a displayed ranking through the computed drivers that explain the difference between the stocks.

SR-02: StockLens shall provide an explanation of each displayed ranking that identifies the ranking’s main computed drivers and their corresponding indicator values.

UC.1.6 (186309) supplies the explanation and UC.1.7 (186503) supplies the dashboard. The skeleton verifies participant wiring; full SR-02 assessment requires computed driver values and stakeholder evaluation.
